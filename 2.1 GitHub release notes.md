## Dying Light Randomiser Mod 2.1

**Download:** `Dying-Light-Randomiser-Mod-2.1.zip` below. Unzip anywhere, run `Randomiser Menu.bat`, press Install.
Updating from 2.0: unzip over the old folder (or into a new one), open the menu, press Install. Your choices carry over; new enemies start switched off.

### New
- **Random encounters** (Harran), in their own menu section:
  - *Randomise encounter enemies*: encounter bandits (Rais's men, Old Town bandits, leaders, riflemen, late-game soldiers, air-drop riflemen) become random specials or another area's humans, and the zombies attacking survivors become random specials.
  - *Random encounter chances*: each encounter type gets a random chance of happening.
- **9 more Hellraid enemies**: shield skeleton, Ghost Dark Knight, Torturer, Dark Torturer (miniboss), fire and lightning priest mages, undead slave, recruit and guard (17 Hellraid enemies in total).
- **Volatiles group**: six Volatile variants the game never spawns normally (group, Suicider, Blistered, final-mission, smaller, no-spit) and the hive brood.
- **Halloween Volatile** added to the event enemies.
- **87 enemies** in the spawn pool, up from 70.

### Fixes
- Encounter enemies only use enemies with a normal human body, so encounter animations play.

### Known issues
- With Hellraid enemies or the "in Harran" Following options on, the Prison map and the Be the Zombie tutorial crash (the menu warns about this).
- Street crowds of special infected can glitch or crash.
